# Davom ettirish

1. Chromium, WebKit, Firefox va Linux Microsoft Edge’dagi public viewport natijalarini saqlang. WebKit sovuq startdagi vaqtinchalik timeoutni trace bilan kuzating. Firefox runtime’ni CI runnerida tasdiqlang.
2. IELTS, CEFR va General English real o‘quv tarkibini izolyatsiya qilingan hisoblar bilan practice, grading va progress orqali sinang.
3. VIP moliya so‘rovlari va DB snapshot yukini profiling qiling. Yangi navbat va pool metrikalari bilan davomli yuk, sovuq start va Render xotira profilini tekshiring.
4. Kutubxonaning oldingi tashqi public PDF manzillarini egasi bilan inventardan tekshiring. Zarur bo‘lsa qaytariladigan private storage ko‘chirishni rehearsal qiling.
5. Haqiqiy mikrofon, Android Chrome, jonli Telegram, Firebase va tasdiqlangan bepul provider dalillarini to‘ldiring.
6. Release gates bo‘yicha Render, backup va rollbackni tasdiqlang. Release SHA uchun fresh GitHub checkout, CI va kerakli ekran dalillarini tasdiqlang.
